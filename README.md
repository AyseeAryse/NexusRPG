# 🌌 NexusRPG

**Космическая настольная RPG с ИИ-гейм мастером**

[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Flask](https://img.shields.io/badge/Flask-3.1-green.svg)](https://flask.palletsprojects.com/)

NexusRPG — это инновационная ролевая игра в сеттинге далёкого космического будущего, где весь игровой процесс управляется искусственным интеллектом. Система поддерживает несколько AI-бэкендов (Ollama, LMStudio, OpenAI, Anthropic) и предоставляет бесконечные возможности для исследования галактики, создания персонажей и проживания уникальных историй.

---

## ✨ Основные возможности

### 🎭 Создание персонажа
- **20+ истоков** происхождения (от техно-жрецов до кочевников пустошей)
- **15+ формативных лет** биографии, влияющих на стартовые навыки
- **10+ специализаций** с уникальными способностями
- Система репутации и психологии персонажа

### 🚀 Исследование мира
- Процедурная генерация галактики с тысячами систем
- Динамические события в реальном времени
- Торговые пути, экономика и крафт
- Политические интриги и фракции

### ⚔️ Боевая система
- Пошаговые тактические бои
- Различные типы урона и защиты
- Модификация оружия и имплантов
- Система критических успехов и провалов

### 🤖 ИИ-Гейм Мастер
- Поддержка локальных моделей (Ollama, LMStudio)
- Облачные API (OpenAI GPT, Anthropic Claude, Google Gemini)
- Контекстная память о событиях кампании
- Адаптивная сложность и повествование

### 🛠 Дополнительные системы
- Квесты и сюжетные линии
- Спутники и компаньоны
- Взлом и кибервойна
- Расследования и детективная механика
- Корабли и недвижимость

## 🚀 Установка и запуск

### Требования
- **Python 3.11** или выше
- **ОЗУ:** минимум 4 ГБ (8+ ГБ рекомендуется для локальных AI-моделей)
- **Диск:** 2 ГБ свободного места

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/AyseeAryse/NexusRPG.git
cd NexusRPG
```

### Шаг 2: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 3: Настройка AI-бэкенда

#### Вариант A: Локальная модель (Ollama) — Рекомендуется
1. Установите [Ollama](https://ollama.ai/)
2. Скачайте модель:
   ```bash
   ollama pull llama3.2
   # или
   ollama pull mistral
   ```
3. Лаунчер автоматически обнаружит Ollama

#### Вариант B: LMStudio
1. Установите [LMStudio](https://lmstudio.ai/)
2. Загрузите любую совместимую модель
3. Запустите локальный сервер в LMStudio

#### Вариант C: Облачные API
1. Получите API-ключ у провайдера:
   - [OpenAI](https://platform.openai.com/api-keys)
   - [Anthropic](https://console.anthropic.com/)
   - [Google AI](https://makersuite.google.com/app/apikey)
2. Создайте файл `.env` в корне проекта:
   ```bash
   cp .env.example .env
   ```
3. Отредактируйте `.env` и добавьте ваш ключ:
   ```
   OPENAI_API_KEY=sk-your-key-here
   # или
   ANTHROPIC_API_KEY=sk-ant-your-key-here
   ```

### Шаг 4: Запуск игры

#### Через лаунчер (рекомендуется)
```bash
python launcher.py
```
Лаунчер проверит зависимости, настроит AI-бэкенд и запустит игру.

#### Прямой запуск сервера
```bash
python src/server/app.py
```
Затем откройте браузер по адресу `http://localhost:5000`

## 🎮 Как играть

1. **Запустите лаунчер**: `python launcher.py`
2. **Выберите AI-бэкенд** в интерфейсе лаунчера
3. **Откройте браузер** по адресу `http://localhost:5000`
4. **Создайте персонажа** через пошаговый мастер
5. **Начните приключение** в процедурно сгенерированной галактике

### Управление
- **Мышь:** навигация по интерфейсу
- **Клавиатура:** ввод действий в диалогах
- **Сохранения:** автоматически в папке `saves/`

## 🔧 Разработка

### Добавление нового контента

1. Создайте файл в `src/content/` или `game_data/active/`
2. Следуйте существующей структуре JSON
3. Добавьте импорты в соответствующие `__init__.py`
4. Протестируйте изменения

### Запуск тестов

```bash
python -m pytest tests/
```

### Сборка исполняемого файла

```bash
pip install pyinstaller
pyinstaller --onefile --name=NEXUS launcher.py
```

> ⚠️ **Важно:** Не коммитьте файлы `.exe`, `_internal/`, `__pycache__/`, `*.pyc` в репозиторий!
