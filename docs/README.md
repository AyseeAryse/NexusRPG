## 🤝 Вклад в документацию

Если вы хотите улучшить документацию:

1. Создайте ветку от `main`
2. Внесите изменения в соответствующий `.md` файл
3. Создайте Pull Request с описанием изменений

Формат файлов: **Markdown (.md)**  
Кодировка: **UTF-8**  
Язык: **Русский** (для пользовательской документации), **Английский** (для API и технической документации)
