# 🏗 Архитектура NexusRPG

## Обзор

## Компоненты

### 1. Веб-клиент (`templates/`, `static/`)

**Технологии:** HTML5, CSS3, Vanilla JavaScript  
**Ответственность:** Отображение интерфейса, обработка ввода пользователя

**Ключевые файлы:**
- `templates/index.html` — главный шаблон
- `static/js/app.js` — клиентская логика
- `static/css/style.css` — стили с glitch-эффектами

---

### 2. Flask Server (`src/server/`)

**Технологии:** Flask 3.1+  
**Ответственность:** HTTP API, WebSocket соединения, маршрутизация запросов

**Ключевые файлы:**
- `app.py` — Flask приложение
- `routes.py` — API эндпоинты

**API Endpoints:**
```
GET  /                    — главная страница
POST /api/character/create — создание персонажа
GET  /api/character/:id    — получение персонажа
POST /api/action           — выполнение действия
GET  /api/world/status     — статус мира
...
```

---

### 3. Game Engine (`src/core/`)

**Технологии:** Python 3.11+  
**Ответственность:** Основной игровой цикл, управление состоянием, правила

**Ключевые классы:**
- `GameState` — хранение состояния игры
- `DiceRoller` — система бросков кубиков (d20, d100, etc.)
- `EventSystem` — обработка игровых событий

---

### 4. AI Module (`src/ai/`)

**Технологии:** requests, openai, anthropic  
**Ответственность:** Взаимодействие с LLM-бэкендами

**Ключевые компоненты:**
- `AIConnector` — унифицированный интерфейс к AI
- `KnowledgeBase` — загрузка и управление контекстом

**Поддерживаемые бэкенды:**
| Бэкенд | Класс | URL по умолчанию |
|--------|-------|------------------|
| Ollama | `OllamaBackend` | `http://localhost:11434` |
| LMStudio | `LMStudioBackend` | `http://localhost:1234/v1` |
| OpenAI | `OpenAIBackend` | `https://api.openai.com` |
| Anthropic | `AnthropicBackend` | `https://api.anthropic.com` |

---

### 5. Systems (`src/systems/`)

**Технологии:** Python 3.11+  
**Ответственность:** Игровые механики и системы

**Модули:**
| Модуль | Файл | Описание |
|--------|------|----------|
| Combat | `combat.py` | Пошаговые бои, урон, защита |
| Quests | `quests.py` | Квесты, цепочки заданий |
| Companions | `companions.py` | Спутники, лояльность |
| Crafting | `crafting.py` | Создание предметов |
| Reputation | `reputation.py` | Отношения с фракциями |

---

### 6. World Module (`src/world/`)

**Технологии:** Python 3.11+, numpy  
**Ответственность:** Генерация и симуляция игрового мира

**Компоненты:**
- `GalaxyMap` — карта галактики с системами
- `WorldSimulator` — симуляция событий в реальном времени
- `ProceduralGenerator` — процедурная генерация контента

---

### 7. Content (`src/content/`)

**Технологии:** Python dataclasses  
**Ответственность:** Статические данные игры

**Структура:**
```
src/content/
├── __init__.py          # Экспорт данных
├── origins.py           # Истоки персонажей
├── perks.py             # Перки и способности
├── items.py             # Предметы
├── npcs.py              # Уникальные NPC
├── world_effects.py     # Глобальные эффекты
├── base.py              # Базовые классы
└── v*_legacy.py         # Legacy данные из старых версий
```

---

### 8. Data Layer (`game_data/`)

**Формат:** JSON  
**Ответственность:** Хранение конфигураций, шаблонов, пресетов

**Структура:**
```
game_data/
├── active/              # Активно используемые данные
│   ├── CHARACTER_*.json
│   ├── COMBAT.json
│   └── ...
├── archive/             # Архивные версии
│   ├── AI_NARRATOR_OLD.json
│   └── ...
└── *.json               # Корневые файлы данных
```

## Поток данных

### Типичный запрос игрока

```
1. Игрок нажимает "Атаковать" в браузере
         │
         ▼
2. JavaScript отправляет POST /api/action
         │
         ▼
3. Flask route принимает запрос
         │
         ▼
4. GameEngine.process_action() обрабатывает
         │
         ├─► CombatEngine.resolve_combat()
         ├─► DiceRoller.roll("1d20+5")
         └─► AIConnector.generate_response()
         │
         ▼
5. Обновление GameState
         │
         ▼
6. Сохранение в saves/
         │
         ▼
7. Возврат JSON ответа клиенту
         │
         ▼
8. JavaScript обновляет UI
```

```
server.app
    └── core.engine
            ├── ai.connector
            │   └── ai.knowledge_base
            ├── systems.combat
```

## Расширение проекта

### Добавление новой игровой системы

1. Создайте файл в `src/systems/new_system.py`
2. Реализуйте класс с методами:
   ```python
   class NewSystem:
       def __init__(self, game_state):
           self.game_state = game_state
       
       def process(self, action_data):
           # Логика обработки
           pass
   ```
3. Добавьте импорт в `src/systems/__init__.py`
4. Интегрируйте в `src/core/engine.py`

### Добавление нового AI-бэкенда

1. Создайте класс в `src/ai/connector.py`:
   ```python
   class NewBackend:
       def generate(self, prompt, context):
           # Логика генерации
           pass
   ```
2. Добавьте выбор бэкенда в конфиг
