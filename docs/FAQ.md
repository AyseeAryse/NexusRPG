# ❓ Частые вопросы (FAQ)

## 🔧 Установка и запуск

### Вопрос: Как установить NexusRPG?
**Ответ:** 
1. Убедитесь, что у вас установлен Python 3.11 или выше
2. Склонируйте репозиторий: `git clone https://github.com/AyseeAryse/NexusRPG.git`
3. Перейдите в папку проекта: `cd NexusRPG`
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите лаунчер: `python launcher.py`

Подробности в разделе [Установка](../README.md#-установка-и-запуск).

---

### Вопрос: Ошибка "ModuleNotFoundError: No module named 'flask'"
**Ответ:** Вы не установили зависимости. Выполните команду:
```bash
pip install -r requirements.txt
```

Если ошибка сохраняется, попробуйте создать виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

---

### Вопрос: Лаунчер не запускается
**Ответ:** Проверьте следующее:
1. Установлен ли Python 3.11+? (`python --version`)
2. Находитесь ли вы в папке проекта?
3. Установлены ли все зависимости?
4. Есть ли права на запись в папку проекта?

Попробуйте запустить с подробным логом ошибок:
```bash
python -u launcher.py 2>&1 | tee launcher.log
```

## 🤖 AI-бэкенды

### Вопрос: Какой AI-бэкенд выбрать?
**Ответ:** 

| Бэкенд | Плюсы | Минусы | Для кого |
|--------|-------|--------|----------|
| **Ollama** | Бесплатно, локально, приватно | Требует RAM 8GB+, медленнее | Рекомендуется всем |
| **LMStudio** | Много моделей, удобный GUI | Требует установки ПО | Новичкам |
| **OpenAI** | Быстро, качественно | Платно, нужен интернет | Продвинутым |
| **Anthropic** | Отличные ответы | Платно, нужен интернет | Продвинутым |

Для начала рекомендуем **Ollama** с моделью `llama3.2`.

---

### Вопрос: Как установить Ollama?
**Ответ:**
1. Скачайте с [ollama.ai](https://ollama.ai/)
2. Установите как обычное приложение
3. В терминале выполните: `ollama pull llama3.2`
4. Лаунчер автоматически обнаружит Ollama

Проверка работы:
```bash
ollama run llama3.2 "Привет!"
```

---

### Вопрос: Ошибка подключения к AI-бэкенду
**Ответ:**
1. Проверьте, запущен ли сервис:
   - Ollama: `ollama list`
   - LMStudio: откройте приложение и включите сервер
2. Проверьте URL в настройках
3. Проверьте брандмауэр/антивирус
4. Посмотрите логи в папке `logs/`

---

### Вопрос: AI отвечает слишком медленно
**Ответ:**
- **Локальные модели:** Используйте меньшую модель (7B вместо 70B), закройте другие приложения
- **Облачные API:** Проверьте интернет-соединение, уменьшите `MAX_TOKENS` в `.env`
- **Любой бэкенд:** Уменьшите температуру (`TEMPERATURE=0.5`)

## 🎮 Игра

### Вопрос: Как создать персонажа?
**Ответ:**
1. Запустите игру через лаунчер
2. Нажмите "Новая игра"
3. Пройдите мастер создания персонажа:
   - Выберите исток происхождения
   - Пройдите формативные годы
   - Выберите специализацию
   - Настройте внешность (опционально)
4. Начните приключение!

---

### Вопрос: Где сохраняются игры?
**Ответ:** Сохранения находятся в папке `saves/` в корне проекта. Файлы имеют формат `.json`.

⚠️ **Важно:** Папка `saves/` исключена из git, поэтому ваши сохранения не попадут в репозиторий.

---

### Вопрос: Как продолжить сохранённую игру?
**Ответ:**
1. Запустите лаунчер
2. Нажмите "Загрузить игру"
3. Выберите файл сохранения из списка
4. Игра продолжится с момента сохранения

---

### Вопрос: Можно ли играть по сети с друзьями?
**Ответ:** В текущей версии (v0.1) мультиплеер не поддерживается. Эта функция запланирована в версии v0.2.

---

## 🐛 Проблемы и ошибки

### Вопрос: Игра вылетает с ошибкой
**Ответ:**
1. Найдите файл лога в папке `logs/`
2. Откройте Issue на GitHub с описанием проблемы
3. Приложите лог-файл и шаги воспроизведения

---

### Вопрос: AI генерирует странный контент
**Ответ:**
- Убедитесь, что используете подходящую модель (рекомендуем `llama3.2` или `mistral`)
- Проверьте настройки температуры (`TEMPERATURE=0.7` — оптимально)
- Попробуйте другой AI-бэкенд

---

### Вопрос: Пропали сохранения
**Ответ:**
1. Проверьте папку `saves/` — файлы должны быть там
2. Если использовали облачное хранилище, проверьте синхронизацию
3. Резервные копии можно найти в `game_data/archive/` (если есть)

**Совет:** Регулярно делайте бэкапы важных сохранений!

---

## 🔧 Разработка

### Вопрос: Как добавить новый контент?
**Ответ:** См. руководство [Создание контента](CONTENT_GUIDE.md).

Кратко:
1. Создайте JSON-файл в `game_data/active/`
2. Или Python-модуль в `src/content/`
3. Добавьте импорты в `__init__.py`
4. Протестируйте изменения

---

### Вопрос: Как запустить тесты?
**Ответ:**
```bash
pip install pytest
python -m pytest tests/ -v
```

С покрытием кода:
```bash
pytest tests/ --cov=src --cov-report=html
```

---

### Вопрос: Как собрать .exe файл?
**Ответ:**
```bash
pip install pyinstaller
pyinstaller --onefile --name=NEXUS launcher.py
```

Файл появится в папке `dist/`.

⚠️ **Важно:** Не коммитьте `.exe` файлы в git! Используйте GitHub Releases.

## 📦 Данные

### Вопрос: Какие файлы в game_data обязательны?
**Ответ:** Все файлы в `game_data/active/` используются игрой. Файлы в `game_data/archive/` — исторические и не требуются.

---

### Вопрос: Можно ли изменить баланс игры?
**Ответ:** Да! Отредактируйте соответствующие JSON-файлы в `game_data/active/` или Python-модули в `src/content/`.

**Совет:** Сначала сделайте копию файла!
